# Madras Magic — Reel Script Guide

This skill cannot generate actual video files. What it can do is write a detailed, shot-by-shot
script grounded in the confirmed reel patterns from `client_profile.md` (section 2.4 and 2.8),
ready to hand to whoever films/edits the actual reel.

## Always state this limitation up front

When asked for a "sample reel," clarify immediately that what follows is a written script/storyboard
for filming, not a generated video, before presenting it — don't let the word "reel" imply a video
file is coming.

## Confirmed reel house style (grounded in real evidence, not assumption)

- **Pacing**: calm, atmospheric, slow reveals — not fast-cut or high-energy. Earlier feedback
  asking to "increase speed" applied to specific clips that felt sluggish/unclear, not a standing
  preference for fast editing. Default to calm pacing unless a brief specifically asks otherwise.
- **Visuals**: dark, moody background (deep teal/black favored), steam or smoke effects rising from
  the dish, dish mostly centered and static rather than tossed/in motion.
- **Text**: progressive reveal animation, Chinese text dominant, appearing gradually rather than
  all at once.
- **Music**: soft/ambient — soft piano or the venue's own original audio. Not upbeat or fast-cut
  music.
- **Length/structure pattern observed**: short build-up (logo/branding) → dish reveal with effects →
  text reveal → hold on final framed shot. Some reels (e.g. the takeaway/Sunday craving reel)
  include a call-to-action text overlay ("Reserve Your Plate Today") near the end.
- **Footage quality matters more than editing tricks**: if source footage looks soft/unclear, that's
  a bigger problem than pacing — ask for raw footage before editing rather than trying to fix
  softness in post.

## Script template structure

When writing a reel script, use this structure so it's actually usable for filming:

```
REEL: [Dish/Campaign Name]
Duration target: [X seconds, typically 15-30s based on observed examples]
Music: [soft piano / original audio / ambient — specify mood, not a specific licensed track unless
        Vengatesh has one in mind]

SHOT 1 (0:00–0:0X) — [e.g. "Branding intro"]
Visual: [logo animates in / dark background fades up]
Text on screen: [if any, with exact Chinese + English wording — flag as draft if not
                  client-verified]
Notes: [pacing guidance, e.g. "hold for 2 seconds, no rush"]

SHOT 2 (0:0X–0:0X) — [e.g. "Dish reveal"]
Visual: [steam rises, dish comes into frame / camera holds static on plated dish]
Text on screen: [...]
Notes: [...]

SHOT 3 ...

FINAL SHOT — [e.g. "Hold + CTA"]
Visual: [...]
Text on screen: [dish name bilingual, standard hashtag block reminder for caption]
Notes: [...]
```

## What to flag every time

- Any on-screen text beyond a dish name already confirmed from approved posts is draft copy and
  needs native-speaker verification before filming/posting.
- If raw footage isn't available yet for a requested dish, say so — a script is only as good as
  the footage it's written for; don't write elaborate camera notes for footage that doesn't exist.
- Music suggestions are mood descriptions, not licensing recommendations — Vengatesh/the client
  would need to actually source a track or use the venue's original audio.
