# Pre-Send Checklists — Madras Magic Restaurant

Run the relevant checklist before sending a draft to the client. These are built directly from
repeat rejection causes in the iteration history (see `client_profile.md` for the evidence behind
each item) — the goal is to catch the high-frequency mistakes before they cost a round.

---

## Universal checklist (every asset, every time)

- [ ] Standard header block used (logo badge + Chinese name + English name + script tagline in the
      established black bar layout) rather than a one-off branding treatment
- [ ] Color palette matches the content bucket (heritage/identity → maroon+gold; premium food hero →
      dark green+gold; casual/lighter promo → cream+photography; trendy/seasonal → bold poster type
      + photo) — pick the bucket before picking colors
- [ ] All English text spell-checked
- [ ] All Chinese text verified by a native speaker or back-translated — not machine-translation-only
- [ ] Restaurant name present and correctly spelled, if the brief implies branding/identity content
- [ ] Any date/year on the design double-checked against the actual current date (a wrong year has
      slipped through before)
- [ ] If a reference image was provided, v1 closely follows its content/style — save creative
      deviation for round 2+, offered as an explicit alternative
- [ ] No AI-look in any food imagery — real photography or photo-grounded edit, styled with props/
      garnish consistent with past approved shots
- [ ] Background vs. text and background vs. food have enough contrast to stay legible
- [ ] Final exported file dimensions match the brief's stated size exactly
- [ ] Bilingual hierarchy followed: Chinese headline dominant/largest, English name secondary below
      or beside it, in distinct typefaces (not just two sizes of the same font)

## Print jobs (posters, banners, stamp cards, resin art)

- [ ] Colors proofed for print, not just screen brightness
- [ ] Exact physical size confirmed (e.g. A3, 6'×10', 64×110, 2-inch) and matched in the export
- [ ] Deliver both JPEG and PDF unless told otherwise (PDF-only has caused loading issues before)
- [ ] Logo background/colors match brand (check if client has specified e.g. black background, or
      logo-matching text color instead of plain white)
- [ ] If Tamil/Indian identity elements are included (statue, script, landmarks), confirm they read
      unambiguously as intended — flag anything that could be misread (e.g. generic arch/dome motifs)
      to Vengatesh before sending
- [ ] If Taiwan local elements are included, prefer specific recognizable landmarks over generic motifs
- [ ] Footer present only if explicitly requested — has been asked to be removed before

## Social media posts (Instagram feed posts)

- [ ] Bilingual text (English + Chinese) included unless the brief clearly says otherwise
- [ ] If it's a "no specific requirement / your own ideas" brief, default to house style
      (food-forward, real photography, bilingual, on-brand color contrast) rather than generic
      restaurant marketing tropes
- [ ] For weekly recurring formats (e.g. Tuesday/Friday post), check which specific dish/theme was
      last used recently to avoid repeating a food item posted too recently
- [ ] Caption uses the standard hashtag block (台灣美食/台北美食/local district tags + 印度咖哩/印度料理) rather
      than improvised tags, unless the post type clearly calls for something different (e.g. event-
      specific tags for the cricket tournament)
- [ ] Chinese caption written first as warm/evocative description; English plays a supporting role
      (dish name/title), not a literal full translation
- [ ] For a new single-dish hero post with no format specified, consider proposing the "calm plate +
      dynamic splash" diptych — it's a proven, reusable template, not just one design's choice

## Reels / video

- [ ] Source footage is sharp/clear — if provided clips look soft, ask for raw footage before editing
      rather than after a rejection
- [ ] Background music included — lean calm/ambient/soft piano as the default house style, not
      upbeat or fast-cut, unless the brief specifically calls for higher energy
- [ ] Pacing matches intent: confirmed house style for hero/product reels is slow, atmospheric reveals
      (steam/smoke effects, progressive text reveal, mostly static dish) — "increase speed" feedback
      from rejection history applied to specific clips that felt sluggish/unclear, not as a standing
      preference for fast-cut editing. Don't default to fast pacing without a specific signal for it.
- [ ] Enough actual food shots/movement, not just text or branding screens
- [ ] If specific days are mapped to specific dishes, confirm the exact dish per day with Vengatesh
      before finalizing (a swap like dosa → ghee dosa has happened before)

## Menu, combo, and pricing graphics

- [ ] Every dish/item listed has both Chinese and English name paired together
- [ ] Prices clearly boxed/badged per item, consistent style across all items in the same graphic
- [ ] Standard header block included even on dense, multi-item layouts
- [ ] If a delivery platform is featured (e.g. Uber Eats), use the platform's official logo/colors
      rather than redrawing it

## Candid / behind-the-scenes content (customer photos, staff moments)

- [ ] These don't need the full branded header/typography treatment — they can be posted simply,
      true to the original photo, rather than over-designed
- [ ] Still appropriate to add the account's name/handle if part of a multi-slide carousel, but don't
      force food-hero-post styling onto an authentic candid moment

## Vague / open briefs ("create your own idea for X post")

- [ ] Don't treat "no requirement" as "no constraints" — apply default house style automatically
- [ ] State your key assumptions explicitly to Vengatesh before finalizing art, e.g. "I'm going with
      [dish], bilingual caption, real photography, light/bright background — flag if you want to
      steer differently"
