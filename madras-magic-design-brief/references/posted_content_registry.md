# Madras Magic — Posted Content Registry

A consolidated list of every dish and design concept already published (confirmed via the
Instagram feed, approvals folder, or other approved sources). Exists to prevent suggesting a dish
or design concept that's already been done — repetition wastes Vengatesh's time and risks boring
the client's audience.

**Always check this file before proposing a new design concept.** If a requested dish or concept
already appears below, say so explicitly and either (a) propose a genuinely different angle/format
for that same dish, or (b) suggest a different dish entirely — don't silently repeat what's listed.

## How entries get added

- **From a sync** ("sync drive" / "sync xl sheet" / "sync everything"): any newly confirmed
  approved post gets logged here with dish name, design concept/format, and source.
- **From direct upload or conversation**: if Vengatesh shares a new approved post or confirms an
  outcome, log it here immediately, the same way it gets logged in `client_profile.md` and
  `assets/iteration_log_template.csv`.
- **Every entry needs a source** — don't add a dish here from guesswork; only from confirmed
  Instagram posts, approvals-folder files, or sheet rows marked approved.

## Workflow: checking before proposing

1. **Dish check**: is the requested/proposed dish already in the table above? If yes, say so and
   either propose a new angle for it or suggest an unposted dish instead.
2. **Format check**: would the proposed layout repeat a format already used for *this same dish*,
   or has the dark-green vertical-stack format already been used too many times in the current
   session? If so, pick a different format from the table, prioritizing ones marked "not yet used
   in any real published post" since those are the freshest options.
3. **State the check explicitly** in the response — e.g. "Sambar hasn't been posted as its own
   design yet, and I'll use the minimal split-screen format since that hasn't appeared in any real
   post." This keeps the reasoning visible rather than silently picked.
4. **After a sync**, re-scan Instagram-sourced approvals (via the approvals folder or live feed
   screenshots Vengatesh shares) for any dish/format not yet in this table, and add it.
