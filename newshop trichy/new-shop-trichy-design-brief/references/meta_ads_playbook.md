## Format specs (standard Meta reference, verify against current Meta docs before final export since these do change)

- **Feed image:** 1:1 (1080x1080) or 4:5 (1080x1350) — 4:5 takes more vertical space in-feed
- **Stories/Reels:** 9:16 (1080x1920), keep key text/CTA within the safe zone (avoid top ~14% and bottom ~20% where UI overlays sit)
- **Carousel:** 1:1 per card, 2–10 cards
- Keep text overlay minimal — Meta doesn't hard-block high text-ratio images anymore but low-text creative still tends to perform better

## Objective-to-format mapping

| Goal | Best format | Notes |
|---|---|---|
| Awareness / launch buzz | Reels, Stories | Motion and native-feeling content outperforms static for cold awareness |
| Foot traffic (drive to store) | Feed image/carousel with location + map pin | Use "near Trichy Junction" / "opposite [landmark]" in copy for local recognizability |
| Offer/promo push | Feed image or carousel with clear price/CTA | Pair with a real expiry date tied to the festival window |

## Targeting notes for this outlet

- Radius targeting centered on Dukes Complex, Bharathiar Salai, Cantonment, Tiruchirappalli 620001 (opposite St. James Matriculation Higher Secondary School, near Domino's, Cantonment)
- Layer in: commuters (interest/behavior: travel, railways), hospital-visitor adjacency is hard to target directly on Meta — lean on geo-radius instead
- This is **not** a student/college-belt audience — don't default to youth-skewed creative unless a specific product justifies it

## Creative rotation rule

Don't run the same static creative through more than one festival window — check `posted_content_registry.md` before reusing an angle, and rotate hooks even within a single campaign to avoid ad fatigue.
